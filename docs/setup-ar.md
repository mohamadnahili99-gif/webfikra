# دليل تفعيل منصة المطاعم — WEBFIKRA

قاعدة بيانات Supabase متصلة الآن بفرع المعاينة `redesign-2026` على Vercel، مع إبقاء التسجيل العام مغلقاً. يجب إنشاء أول حساب مطعم عبر Supabase Auth واختبار تسجيل الدخول الحقيقي قبل تشغيل الخدمة للعملاء. لا تغيّر الفرع `main` إلا بعد المراجعة.

## 1. قاعدة البيانات
افتح مشروع Supabase الصحيح ثم SQL Editor، ونفّذ بالترتيب:

1. `supabase/migrations/20261119_webfikra_platform.sql`: جداول المطاعم والأقسام والأصناف مع صلاحيات RLS، وإمكانية إضافة أسماء وأوصاف بالإنجليزية.
2. `supabase/migrations/20261119_webfikra_media.sql`: تخزين صور JPG/PNG/WebP حتى 5 MB، بصلاحيات رفع لصاحب المطعم فقط.
3. `supabase/migrations/20261120_webfikra_security_hardening.sql`: يمنع صلاحيات TRUNCATE/TRIGGER/REFERENCES الخطرة ويصحح شرط ملكية مسار الصور.

**تم تطبيق الترحيلات الثلاثة على مشروع Supabase `webfikra-platform`.** ونجحت اختبارات RLS بمعاملة مؤقتة تتراجع عن أي بيانات اختبار. لا تُكرر تشغيل الملفات القديمة على قاعدة البيانات دون مراجعة سجلات الترحيلات.

لا تنفّذ هذه الأوامر على قاعدة بيانات فيها تعديلات أخرى دون مراجعة نسخة احتياطية.

## 2. إعداد حسابات المطاعم
في Supabase > Authentication فعّل البريد الإلكتروني وتأكيد البريد. أنشئ أول حساب من لوحة Supabase أو أرسل دعوة له. اضبط SMTP وتحديد المعدلات وحماية التسجيل قبل فتح التسجيل لأي زائر.

## 3. ربط Vercel
في إعدادات مشروع WEBFIKRA على Vercel أضف:

- `SUPABASE_URL`: رابط مشروع Supabase الكامل
- `SUPABASE_PUBLISHABLE_KEY`: المفتاح العام من Supabase (وليس `service_role` مطلقاً)
- `WEBFIKRA_ALLOW_SIGNUPS=false`: اترك التسجيل العام مغلقاً بدايةً
- `NEXT_PUBLIC_SITE_URL=https://webfikra.com` (اختياري للعنوان الرسمي)

**تم ضبط المتغيرات الثلاثة الأولى لفرع `redesign-2026` في Vercel وإعادة نشر المعاينة بنجاح.** لم تُضبط على الإنتاج. لا ترسل كلمات المرور أو المفاتيح السرية عبر المحادثة أو GitHub.

## 4. تجربة النظام
ادخل إلى `/restaurants/login`، ثم افتح `/restaurants/portal` وأضف مطعماً. احفظ بياناته، ارفع الشعار والغلاف والأصناف، أنشئ الأقسام، ثم فعّل «نشر المنيو». ستجد القائمة في `/r/restaurant-slug`.

منيو الزبون يعرض الأصناف ويسمح بالسلة وزيادة أو تقليل الكميات وكتابة الاسم والعنوان والملاحظات وإعداد رسالة طلب واتساب. **لا يضيف أي رسوم توصيل**. الزبون يرسل الرسالة بنفسه.

يوفر المحرّر ألواناً وعناوين وساعات عمل وحسابات اجتماعية وحقولاً اختيارية بالإنجليزية. يمكن عرض QR للقائمة المنشورة عبر خدمة خارجية تتلقى رابط المنيو العام فقط.

## 5. مراجعة الأمان قبل النشر
اجتزنا اختبار SQL قابل للتراجع بعزل هويتين افتراضيتين: منعنا التعديل المتبادل، والتأكدنا من قراءة المسودات والصور. **لا يزال اختبار حسابين فعليين من خلال المتصفح واجباً قبل الإطلاق.** جرّب بحسابي مطعم مختلفين: يجب ألا يستطيع أحدهما قراءة أو تعديل مطعم الآخر. تأكد أن المطعم غير المنشور والصنف المخفي لا يظهران للزوار. اختبر تسجيل الدخول وخروج الجلسة وتجديدها، ورفع الصور، وإرسال رسالة واتساب، والعربية والإنجليزية.

**ليس متوفراً بعد:** تتبّع الطلبات وتخزينها في قاعدة البيانات، استلام مدفوعات، إدارة المخزون، توجيه الطلب آلياً للمطبخ، دومين مستقل لكل مطعم، أو ضمان وصول رسائل واتساب. هذه خدمات منفصلة ولا يجب الإعلان عنها كمميزات عاملة.
